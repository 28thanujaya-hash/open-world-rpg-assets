# open-world-rpg-assets

Public files for the open-world RPG, so web tools (three.ws, glTF viewers) can load them by link.
Only free, CC0-based character files live here. The game itself stays in a private repo.

## characters/family
Six villagers (husband, wife, grandfather, grandmother, boy, girl). Each `.glb` is one rigged character
on the shared 65-bone Quaternius skeleton, with all 84 moves included.
